# Student Grade Calculator

## 📌 Project Overview

The **Student Grade Calculator** is a simple Python mini project designed to calculate a student's total marks, percentage, and grade based on marks obtained in five subjects.

This project is suitable for beginners who are learning Python programming and demonstrates the use of input, arithmetic operations, conditional statements, and output formatting.

## 🎯 Objectives

- Calculate the total marks obtained by a student.
- Calculate the student's percentage.
- Determine the grade based on the percentage.
- Display the student's details and final result clearly.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Development Environment:** Pydroid 3 / Python IDE
- **Version Control:** GitHub

## 📚 Subjects

The calculator accepts marks for:

1. Python
2. DBMS
3. Java
4. Computer Network
5. Data Structure

Each subject is calculated out of 100 marks.

## ⚙️ Features

- Student name input
- Register number input
- Marks input for five subjects
- Total marks calculation
- Percentage calculation
- Automatic grade calculation
- Simple and beginner-friendly interface

## 📊 Grading System

| Percentage | Grade |
|------------|-------|
| 90% – 100% | A+ |
| 80% – 89% | A |
| 70% – 79% | B |
| 60% – 69% | C |
| 50% – 59% | D |
| Below 50% | F |

## ▶️ How to Run

1. Install Python 3 or use a Python IDE such as Pydroid 3.
2. Download or clone this repository.
3. Open `student_grade_calculator.py`.
4. Run the program.
5. Enter the student's name and register number.
6. Enter marks for all five subjects.
7. The program will display the total marks, percentage, and grade.
