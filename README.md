🎓 Student Grade Calculator

A simple and beginner-friendly Python Student Grade Calculator that calculates total marks, average, percentage, and grade based on the marks entered by the user.

📌 Project Overview

The Student Grade Calculator is a Python-based mini project developed to practice basic programming concepts.

The program takes the student's details and marks in different subjects as input and calculates the student's academic performance.

✨ Features

- 👤 Enter student name
- 🆔 Enter register number
- 📝 Enter marks for different subjects
- ➕ Calculate total marks
- 📊 Calculate average marks
- 📈 Calculate percentage
- 🏆 Calculate grade
- 📋 Display the final result clearly

💻 Technologies Used

- Python 3
